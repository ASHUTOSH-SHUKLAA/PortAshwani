# Images Directory

Place your media files in the following locations:

## Profile Image
- `profile.jpg` — Your professional headshot or creative portrait

## Hero Section
- `hero-poster.jpg` — Static fallback for hero background (1920×1080 recommended)

## Projects (in /projects/)
- `horizon-drift-thumb.jpg` — Project 01 thumbnail
- `pulse-campaign-thumb.jpg` — Project 02 thumbnail
- `frequencies-thumb.jpg` — Project 03 thumbnail
- `inner-frame-thumb.jpg` — Project 04 thumbnail
- `reels-thumb.jpg` — Project 05 thumbnail
- `depth-of-field-thumb.jpg` — Project 06 thumbnail

## Before/After (in /before-after/)
- `raw.jpg` — Raw/ungraded footage frame
- `graded.jpg` — Final colour-graded frame

## Recommended sizes
- Thumbnails: 1920×1080 (16:9) or 1280×720 for smaller cards
- Profile: 800×1067 (3:4 portrait)
- Before/After: 1920×1080

## Image optimisation tips
- Use WebP format for better compression where possible
- Keep thumbnail file sizes under 500KB each
- Use JPEG quality 80-85% for photos
